# News Portal Project
Учебный проект новостного портала на Django.

## Реализованный функционал:
- Вывод списка новостей из базы данных.
- Фильтрация и цензурирование текста (Custom Filters).
- **Постраничный вывод (Pagination)** — по 10 новостей на страницу.
- Детальная страница каждой новости.

## Как запустить:
1. Установить зависимости: `pip install -r requirements.txt`
2. Выполнить миграции: `python manage.py migrate`
3. Запустить сервер: `python manage.py runserver`
